## Controller and bounded comparison

Config 9 uses consumed pointer velocity plus bounded positional correction:

```text
correction = limit_vector(6 * (target - physical_head), 900)
desired = limit_vector(limit_vector(pointer_velocity, 1800) + correction, 1800)
command = exponential low-pass(desired, tau=0.060 seconds)
```

The command filter advances at the existing <=2-ms paddle substeps. The existing physical velocity relaxation is 0.045 seconds. Initial pointer placement is an anchor, not a velocity burst. Reset clears the controller history. Recovery blends into this command. Position is integrated continuously, with existing acceleration bounds; this does not introduce a separate jerk limiter or claim a biomechanical hand model. Phase/boundary constraints retain their existing behavior.

The approach/overall speed limits remain 1,800 / 3,200 units/s, acceleration remains 18,000 units/s^2, and committed-swing mapping and phase durations are unchanged. Center inset remains zero; the full head collision disk may extend outside the viewport. No fly position, threat state, pointer speed or acceleration enters neural policy observations. ## Recorder and replay

Schema 3 reports threat/ecology fractions and fly-speed distributions separately over all recorded ticks and post-step-alive ticks. Fatal ticks are excluded from the alive population. Empty populations are explicit. Legacy unqualified state fractions retain the all-tick denominator; legacy speed uses pre-step-alive ticks. Prefer the explicit new fields.

Alive APPROACH summaries include pointer/head percentiles, target error and fraction at >=95% of the configured cap. Episode-first pointer samples are excluded. WORLD control diagnostics are recorded separately and never added to the policy whitelist.

Manifests record actual Numba thread count and threading layer. Replay restores the recorded count with the initialized Numba pool API, checks the layer and restores the caller's count afterward. If the initialized pool is too small, it fails clearly with the required `NUMBA_NUM_THREADS` setting. Late environment/config changes cannot be assumed to resize that pool. Historical schema-1/2 recordings still require their archived source and compatible original runtime.

## Recorder and deterministic replay

Schema 1 records fixed 20 ms simulation ticks (50 Hz), separately from last-render
presentation timing. Includes fly kinematics, retinal scalars, LC4/LPLC2 input and
actual activity summaries, descending readouts, threshold/refractory, action,
saccades, ecology, local cues, applied speed, paddle dynamics, outcomes and WORLD
debug. Policy observations remain in a separate unchanged whitelisted file.
No full-neuron default dump exists; optional future sparse/low-frequency/event
capture is designed but not implemented. See [complete schema/usage](../../game/SESSIONS.md).

Input ordering includes consumed pointer positions, tick clicks, between-tick
click acceptance, reset seeds and pause events. Replay requires recorded config,
matching calibration, source snapshot, Python/dependency versions and dataset
hashes. Every deterministic recorded tick field is hashed and compared exactly;
wall pause duration and render timing are excluded. This does not establish
whole-brain bit equality or portability across different CPUs/libraries.

Final synthetic example: `20260920T025537.337314Z-578d71bd` under `results/game/sessions/`.
It contains manifest/source archive, inputs, ticks, policy observations, events,
episode records, indexed strikes, summary JSON, automatic REPORT.md and replay
verification. The script is `python tools/session_sanity.py`; a rerun creates a
new directory. Durable summary: [session_m1_7.json](session_m1_7.json).

- 24 simulation seconds; 3 episodes; 7 accepted strikes; 1 hit and 6 misses.
- 31 ALERT onsets, 7 ESCAPE onsets, 17 DNp01 threshold crossings.
- Conditional latency: n=4, mean 0.32 s, median 0.22 s.
- Mean living-tick speed 10.280 BL/s; peak 41.244 BL/s.
- 7,089,870 bytes across top-level session files (approximately 7.09 MB).
- Generation plus exact replay: 11.520 s in this run.

These are fixture observations, not human performance, connectivity advantage or
biological validation. Escape action counts differ from ESCAPE state onsets;
summary fields distinguish them. Legacy flight can exceed ecology's requested
speed transiently; M1.7 does not implement the deferred universal-speed calibration.

## Physical parameters and collision

ROOM alone enables bounded paddle dynamics: 200 ms recent input, approach cap
1,800 units/s, overall cap 3,200 units/s, acceleration cap 18,000 units/s^2,
angular caps 6 rad/s and 24 rad/s^2. Base swing target is 320 units/s, plus
0.9 times approach speed and 0.025 times positive acceleration trend, capped
at 3,200. Position gain is 12/s and velocity relaxation 45 ms.

APPROACH is free; COMMIT 100 ms, FAST_SWING 120 ms, ACTIVE_CONTACT 100 ms,
FOLLOW_THROUGH 140 ms and RECOVERY 300 ms make a 760 ms committed cycle.
Paddle substeps are <=2 ms and split phase boundaries. Swept disk collision
uses relative head/fly segments during active contact, with the fly interpolated
within each 20 ms tick. This prevents endpoint tunneling while retaining a
piecewise-linear collision approximation. It is not measured human biomechanics.

## Known limits and next human test

- Balance and visible timing require the owner's human playtest; scripted native
  input proves rendering/control operation only.
- Clean close is required for finalized summaries/exact replay. Abruptly terminated
  logs are marked incomplete; partial recovery is manual.
- JSONL is verbose (this fixture about 0.30 MB per simulation second).
  Sessions are ignored by Git and should be managed as local analysis data.
- One writer per profile directory; historical profile counters are not merged.
- Strike latency is conditional on a measurable new escape before the next strike;
  incomplete/preexisting events are excluded. It is not a causal latency estimate.
- Replay is currently for FixedEscapePolicy with the same source/environment.
- Landing remains an approach-only ecology state; no physical perching was added.
